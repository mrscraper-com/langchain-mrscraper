---
title: "MrScraper get-screenshot"
---

`mrscraper_get_screenshot`: Full-page or top-viewport base64 screenshot.

Input: `{"url":"https://books.toscrape.com/"}`; pass service-specific snake_case options as needed.

Supports `invoke` and `ainvoke`. Returns a JSON string containing `status_code`, `data`, and `headers`. See the [SDK README](https://github.com/mrscraper-com/langchain-mrscraper#readme) for all options.
