---
title: "MrScraperScreenshot migration"
description: "Use MrScraperScraperAPI instead of MrScraperScreenshot."
---

`MrScraperScreenshot` (`mrscraper_get_screenshot`) was removed in langchain-mrscraper 0.4.0 because `mrscraper-sdk` 0.8.0 no longer exposes a format-specific method. Use [`MrScraperScraperAPI`](/oss/python/integrations/tools/mrscraper_scraper_api) (tool name `mrscraper_scraper_api`) with `{"url": ..., "html": False, "screenshot": True}`. Combine `html`, `markdown`, and `screenshot` to get several outputs from one request. Screenshot output enables browser rendering automatically. The 0.3.x `full_page` option and the 300-second/`domcontentloaded` defaults no longer apply; pass `timeout` and `wait_until` explicitly if you need them.

See the [MrScraper provider page](/oss/python/integrations/providers/mrscraper) for the three current tools.
