---
title: "MrScraperMarkdown migration"
description: "Use MrScraperScraperAPI instead of MrScraperMarkdown."
---

`MrScraperMarkdown` (`mrscraper_scraper_markdown`) was removed in langchain-mrscraper 0.4.0 because `mrscraper-sdk` 0.8.0 no longer exposes a format-specific method. Use [`MrScraperScraperAPI`](/oss/python/integrations/tools/mrscraper_scraper_api) (tool name `mrscraper_scraper_api`) with `{"url": ..., "html": False, "markdown": True}`. Combine `html`, `markdown`, and `screenshot` to get several outputs from one request.

See the [MrScraper provider page](/oss/python/integrations/providers/mrscraper) for the three current tools.
