---
title: "MrScraperAccount integration"
description: "Read account usage and quota using MrScraper in LangChain."
---

`MrScraperAccount` wraps the Python SDK's `account` service and is registered as `mrscraper_account`.

## Setup and invocation

```bash
pip install -U langchain-mrscraper
```

```python
from langchain_mrscraper import MrScraperAccount

tool = MrScraperAccount(token="your-api-token")
result = tool.invoke({})
print(result)
```

Use `await tool.ainvoke(...)` for async invocation. Authentication also supports `mrscraper_api_key`, `MRSCRAPER_API_KEY`, or `MRSCRAPER_API_TOKEN`; an existing SDK client can be supplied with `client=...`.

## Parameters and behavior

Returns account identity, subscription status, token usage/limits, quota remaining, and rate limits. `timeout` defaults to 30 seconds and must be positive.

## Result format

Tool output is a JSON string with `status_code`, `data`, and `headers`. `data` contains `subscription_status`, `enterprise`, `token_usage`, `token_limit`, `token_remaining`, `usage_percent`, `rate_limit`, `rate_ttl`, `auto_renew`, `ends_at`, and `user` (`name`, `email`, `verified`). API tokens and billing identifiers are not included.
