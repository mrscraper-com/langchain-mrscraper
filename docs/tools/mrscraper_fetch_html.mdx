---
title: "MrScraperFetchHTML migration"
description: "Use MrScraperScraperAPI with the current MrScraper SDK."
---

The `MrScraperFetchHTML` import alias was removed in 0.5.0. Use [`MrScraperScraperAPI`](/oss/python/integrations/tools/mrscraper_scraper_api) (tool name `mrscraper_scraper_api`); it returns HTML by default. Set `browser_rendering=True` when JavaScript rendering is needed.

See the [MrScraper provider page](/oss/python/integrations/providers/mrscraper) for the three current tools.
