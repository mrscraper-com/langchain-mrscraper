---
title: "MrScraperFetchHTML migration"
description: "Use MrScraperHTML with the current MrScraper SDK."
---

`MrScraperFetchHTML` remains an import alias for `MrScraperHTML`. Its registered tool name is now `mrscraper_scraper_html`. Update toolkit filters and use the [current service documentation](/oss/python/integrations/tools/mrscraper_scraper_html).

The HTML service chooses HTML output automatically. Set `browser_rendering=True` when JavaScript rendering is needed; HTML, Markdown, and screenshot output flags are absent from tool inputs.
