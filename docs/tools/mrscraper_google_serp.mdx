---
title: "MrScraperGoogleSerp migration"
description: "Use MrScraperWebSearch with the current MrScraper SDK."
---

`MrScraperGoogleSerp` remains an import alias for `MrScraperWebSearch`. Its registered tool name is now `mrscraper_web_search`. Update toolkit filters and use the [current service documentation](/oss/python/integrations/tools/mrscraper_web_search).

The Google search service accepts query text or a Google search URL and uses the SDK v2 sync service. For parsed JSON, pass `raw=False` and `format="json"`; the old `session_cookie` argument is removed.
