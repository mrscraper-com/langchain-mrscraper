---
title: "Web Search migration"
description: "Migrate to the MrScraper Web Search tool."
---

Use `MrScraperWebSearch` and the tool name `mrscraper_web_search`. Update toolkit filters and follow the [Web Search documentation](/oss/python/integrations/tools/mrscraper_web_search).

Search the web to retrieve real-time search results, including relevant website URLs, titles, descriptions, and related questions based on a given query. Pass the query in `url`. For parsed JSON, set `raw=False` and `format="json"`. The old `session_cookie` argument is removed.
