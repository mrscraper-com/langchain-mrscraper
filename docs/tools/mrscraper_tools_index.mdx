This package exposes 8 LangChain tools powered by `mrscraper-sdk`.

## Installation

```bash
pip install -U langchain-mrscraper
```

## Toolkit usage

```python
import os
from langchain_mrscraper import MrScraperToolkit

# Option 1: pass key directly
tools = MrScraperToolkit(mrscraper_api_key="your-api-key").get_tools()

# Option 2: auto-read from environment variable
os.environ["MRSCRAPER_API_KEY"] = "your-api-key"
tools = MrScraperToolkit().get_tools()
```

## Tools

- `MrScraperFetchHTML`
- `MrScraperCreateScraper`
- `MrScraperRerunScraper`
- `MrScraperBulkRerunAIScraper`
- `MrScraperRerunManualScraper`
- `MrScraperBulkRerunManualScraper`
- `MrScraperGetAllResults`
- `MrScraperGetResultById`
