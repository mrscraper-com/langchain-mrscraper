This legacy tool has been removed because its SDK method is absent from `mrscraper-sdk`. It is not exported or included in the current toolkit.

The current tools return their API results directly; there is no stored-result listing tool.

See the [MrScraper provider page](/oss/python/integrations/providers/mrscraper) for the three current tools.
