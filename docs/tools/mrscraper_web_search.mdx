---
title: "MrScraperWebSearch integration"
description: "Search Google synchronously using MrScraper in LangChain."
---

`MrScraperWebSearch` wraps the Python SDK's `web_search` service and is registered as `mrscraper_web_search`.

## Setup and invocation

```bash
pip install -U langchain-mrscraper
```

```python
from langchain_mrscraper import MrScraperWebSearch

tool = MrScraperWebSearch(token="your-api-token")
result = tool.invoke({"url": "Cayman Islands real estate", "raw": False, "format": "json", "region": "us", "language": "en", "page": 1})
print(result)
```

Use `await tool.ainvoke(...)` for async invocation. Authentication also supports `mrscraper_api_key`, `MRSCRAPER_API_KEY`, or `MRSCRAPER_API_TOKEN`; an existing SDK client can be supplied with `client=...`.

## Parameters and behavior

Accepts query text or a Google search URL and delegates to the SDK v2 sync service (`/api/google/serp/v2/sync`). For compatibility `raw=True` is the default and selects HTML regardless of `format`; set `raw=False` for JSON. Optional controls are `region`, `language`, `page` (one-based), `render_js` (default false), and `timeout` (default 600 seconds).

## Result format

Tool output is a JSON string with `status_code`, `data`, and `headers`. Text and JSON are preserved. Binary images and ZIP files use `{"encoding": "base64", "base64": "...", "size_bytes": 123}` in `data`; decode with `base64.b64decode(result["data"]["base64"])` after `json.loads(...)`. The response content type is retained in `headers`.
