---
title: "MrScraper Scrape brand"
---

Extract a website's colors, typography, logos, and social links as JSON.

Tool: `mrscraper_scrape_brand`. Supports `invoke` and `ainvoke`.

## Parameters

| Parameter | HTTP field | Type | Default  | Description                                        |
| --------- | ---------- | ---- | -------- | -------------------------------------------------- |
| `url`     | `url`      | str  | Required | Absolute HTTP or HTTPS URL of the page to process. |

## Example

```python
import json
from langchain_mrscraper import MrScraperScrapeBrand

result = json.loads(MrScraperScrapeBrand().invoke({'url': 'https://example.com'}))
print(result["data"])
```

## Response

The response body preserves the API brand result. Brand data is typically available at data.data.brand in the response envelope.

Returns a JSON string with status_code, data, and headers. See the [README](../../README.md) for authentication and integration details.
