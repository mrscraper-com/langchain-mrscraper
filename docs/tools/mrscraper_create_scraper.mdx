description: "Migrate from the earlier MrScraper integration."

This legacy tool has been removed because its SDK method is absent from `mrscraper-sdk>=0.7.0`. It is not exported or included in the current toolkit.

Use `MrScraperJSON` for general extraction, `MrScraperMultiplePage` for listing extraction, or `MrScraperSitemap` for map discovery. Rename extraction `message` to `prompt`; each tool chooses its agent automatically.

See the [MrScraper provider page](/oss/python/integrations/providers/mrscraper) for the ten current services.
