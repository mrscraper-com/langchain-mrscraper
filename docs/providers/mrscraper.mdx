---

The integration exposes the three public services from `mrscraper-sdk>=0.9.0,<0.10.0`: the Scraper API (HTML, Markdown, screenshot, or a combination), Web Search, and account usage.

## Installation and setup

```bash
pip install -U langchain-mrscraper
```

```python
import os
from langchain_mrscraper import MrScraperToolkit

os.environ["MRSCRAPER_API_KEY"] = "your-api-token"
tools = MrScraperToolkit().get_tools()
```

`token`, `mrscraper_api_key`, `MRSCRAPER_API_KEY`, and `MRSCRAPER_API_TOKEN` are supported. Inject an SDK client with `client=...`, or select exact tool names with `tool_names=["mrscraper_scraper_api", "mrscraper_web_search"]`. Every tool supports both `.invoke(...)` and `await .ainvoke(...)`.

## Current tool integrations

- [MrScraperScraperAPI](/oss/python/integrations/tools/mrscraper_scraper_api) — Fetch a public web page as rendered HTML, Markdown, screenshot, or a combination.
- [MrScraperWebSearch](/oss/python/integrations/tools/mrscraper_web_search) — Search the web for real-time results: website URLs, titles, and descriptions.
- [MrScraperAccount](/oss/python/integrations/tools/mrscraper_account) — Read account usage and quota.

## Migration from 0.3.x

Version 0.5.0 follows `mrscraper-sdk` 0.9.0, which exposes exactly three public methods.

- `MrScraperHTML`, `MrScraperMarkdown`, and `MrScraperScreenshot` are replaced by `MrScraperScraperAPI` (`mrscraper_scraper_api`). Select outputs with the `html`, `markdown`, and `screenshot` flags.
- `MrScraperJSON`, `MrScraperMultiplePage`, `MrScraperSitemap`, `MrScraperBrand`, and `MrScraperGetBrand` are removed because the SDK no longer exposes those services. Fetch pages with `MrScraperScraperAPI` and let your model extract the data, or pin `langchain-mrscraper<0.4`.
- `MrScraperWebSearch` now takes `query`, `country`, and `num_results` (10–100) instead of `url`, `raw`, `format`, `region`, `language`, `page`, and `render_js`.
- The `MrScraperFetchHTML` import alias is removed; use `MrScraperScraperAPI`.

Tool results are JSON strings with `status_code`, `data`, and `headers`.
