[MrScraper](https://mrscraper.com) provides web scraping APIs for rendered HTML retrieval, AI-based extraction, scraper reruns, and result management.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-mrscraper
```

```bash uv
uv add langchain-mrscraper
```
</CodeGroup>

Set your API token:

```python
import os
os.environ["MRSCRAPER_API_KEY"] = "your-api-token"
```

## Toolkit

```python
from langchain_mrscraper import MrScraperToolkit

tools = MrScraperToolkit().get_tools()
```
