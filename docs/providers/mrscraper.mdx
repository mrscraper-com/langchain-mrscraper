The integration exposes all ten public services from `mrscraper-sdk>=0.7.0`: HTML, Markdown, screenshots, JSON extraction, listing extraction, sitemap discovery, brand jobs, Google search, and account usage.

## Installation and setup

```bash
pip install -U langchain-mrscraper
```

```python
import os
from langchain_mrscraper import MrScraperToolkit

os.environ["MRSCRAPER_API_KEY"] = "your-api-token"
tools = MrScraperToolkit().get_tools()
```

`token`, `mrscraper_api_key`, `MRSCRAPER_API_KEY`, and `MRSCRAPER_API_TOKEN` are supported. Inject an SDK client with `client=...`, or select exact tool names with `tool_names=["mrscraper_scraper_json", "mrscraper_scraper_sitemap"]`. Every tool supports both `.invoke(...)` and `await .ainvoke(...)`.

## Current tool integrations

- [MrScraperHTML](/oss/python/integrations/tools/mrscraper_scraper_html) — Retrieve page HTML.
- [MrScraperMarkdown](/oss/python/integrations/tools/mrscraper_scraper_markdown) — Retrieve page Markdown.
- [MrScraperScreenshot](/oss/python/integrations/tools/mrscraper_get_screenshot) — Capture a page screenshot.
- [MrScraperJSON](/oss/python/integrations/tools/mrscraper_scraper_json) — Extract structured page data.
- [MrScraperMultiplePage](/oss/python/integrations/tools/mrscraper_scraper_multiple_page) — Extract entries across listing pages.
- [MrScraperSitemap](/oss/python/integrations/tools/mrscraper_scraper_sitemap) — Discover URLs from a site.
- [MrScraperBrand](/oss/python/integrations/tools/mrscraper_scrape_brand) — Start a brand scraping job.
- [MrScraperGetBrand](/oss/python/integrations/tools/mrscraper_get_brand) — Read or download a brand job.
- [MrScraperWebSearch](/oss/python/integrations/tools/mrscraper_web_search) — Search Google synchronously.
- [MrScraperAccount](/oss/python/integrations/tools/mrscraper_account) — Read account usage and quota.

## Migration

`MrScraperFetchHTML` and `MrScraperGoogleSerp` remain import aliases for `MrScraperHTML` and `MrScraperWebSearch`, with current tool names. The old create/rerun/bulk/result-management operations are removed. Use `MrScraperJSON` / `MrScraperMultiplePage` with `prompt` for extraction and `MrScraperSitemap` for discovery.

The shared low-level scraper API remains internal. Format-specific tools do not expose HTML, Markdown, or screenshot flags. Binary tool results use a lossless base64 envelope; see the screenshot or brand-download documentation.
